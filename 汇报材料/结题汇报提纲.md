# 结题汇报提纲：BIPIA 四组对照

1. **研究问题**：邮件和表格中的外部文字如何诱导模型偏离用户问题？引用 [BIPIA 原论文](https://arxiv.org/abs/2312.14197)与官方仓库。
2. **复现边界**：官方 EmailQA、TableQA、两条攻击与两个注入位置；跨模型使用 DeepSeek；只算完整短语 ASR 和答案字符串命中，不等同官方完整基准或 ROUGE-1。
3. **实验设计图**：A 官方原始提示、B 官方显式提醒、C 角色隔离、D 隔离＋证据筛选。标出可信 system 指令与低信任外部内容的边界；解释 D 的问题相关筛选规则及其可能删错证据的风险。
4. **配对与可复现性**：同一批上下文给四组；固定种子 2023；列出实际样本数、模型返回名、温度、输出长度、上游版本及 `config.json` 的 SHA-256。
5. **结果页**：打开两个真实运行目录的 `report.html`，分别展示 TableQA 与 EmailQA 的 ASR、官方正常任务、课程难例、平均 token 和延迟。若尚无 `complete` 运行，讲清楚只有代码与测试结果，不展示虚构模型指标。
6. **同例分析**：选择同一攻击与上下文在四组下的逐条回复；展示完整短语命中与漏判的差别。用 `manual_review.json` 给出人工判断及证据。
7. **可行性与局限**：小样本、两条攻击、不同模型、字符串代理、证据筛选可能丢答案、模型输出波动、课程难例为自编而非官方基准。只对本次数据和设置下的观察下结论。

具体命令、数据来源和结果表模板见 [课程复现说明](../课程复现说明.md)。
